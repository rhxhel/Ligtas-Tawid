About the system

Built around people

Crossing the road should never feel like a risk.

Ligtas Tawid is a sensor-based pedestrian crossing signal designed for two-way midblock roads with a median island. It runs like a normal traffic light, cycling through green, yellow, and red. When pedestrians wait at the curb long enough, the system changes the light early, stopping vehicles on both roads so people can cross safely.

A cooldown after each green prevents repeated interruptions, and a waiting-time filter ignores people who only pass by. The miniature prototype uses an Arduino Uno, infrared sensors, LED signals, and a countdown display, and a web control panel lets you adjust the timings and sensor settings and keep a record of the signal’s activity.

01

Statement of the problem

Why a smarter crossing is needed

Crossing a two-way road away from an intersection is risky for pedestrians. Motorists often do not notice or yield to people waiting at the curb, especially on wide roads with a median. Fixed-timer signals do not solve this. They either stop vehicles when no one is crossing, or make pedestrians wait when many have gathered. Manual traffic direction takes personnel, and it is not available at every crossing.

Guide questions

Specifically, the project seeks to answer the following:

  1. How can a signal detect pedestrians waiting at the curb without a person operating it?
  2. How can the system avoid reacting to people who only pass by?
  3. How can the signal change for waiting pedestrians without being triggered again and again?
  4. How can the signal’s timings and sensor settings be adjusted without editing the program?
02

Objectives

What the system aims to achieve

To design and build a miniature sensor-based pedestrian crossing signal that detects waiting pedestrians and stops traffic on both roads when a set number is reached, improving crossing safety.

Specific objectives

  1. To detect waiting pedestrians at the curb using infrared sensors.
  2. To count a person as waiting only after staying for a set time, so passersby are ignored.
  3. To change the signal early from green to yellow, then red, when the required number of waiting pedestrians is reached, and to keep the normal cycle otherwise.
03

Scope and limitations

What it covers, and what it doesn't

Ligtas Tawid is meant for midblock crossings where the number of pedestrians changes during the day, and a signal that only follows a timer would often stop vehicles for no one. The scope of the project covers the following:

Scope

  • Two-way midblock roads with a median island.
  • Roads that become busy only at certain times of the day, so pedestrian traffic changes a lot.
  • Suitable locations include schools, hospitals and health centers, markets and terminals, and barangay halls, churches, and parks.
  • The normal cycle keeps running when few people wait, and the light changes early only when the required number of pedestrians have waited long enough.
  • Demonstrated as a miniature prototype, using figurines to represent pedestrians.

Limitations

  • Not suitable for very busy roads, where constant pedestrian crowds would trigger the signal almost all the time and heavy, continuous vehicle flow could cause long queues.
  • Not suitable for fast highways and expressways, which need much longer warning distances.
  • Not meant for intersections that already have signals.
  • The system does not detect vehicles, so it cannot adapt to traffic flow.
  • The infrared sensors detect only whether an object is present at one spot, not how many people are there.
04

Recommendations

Where the system can go next

Based on the limitations of the prototype, we recommend the following for future work.

  1. Add more sensors, or camera-based detection, to reduce false triggers and cover wider waiting areas.
  2. Use a weather-resistant enclosure and outdoor-rated sensors for real roadside conditions.
  3. Add an audio cue and a push button so visually impaired and elderly pedestrians are also served.
  4. Pilot the system at an actual midblock crossing and use real traffic data to tune the timings.

Core prototype hardware
